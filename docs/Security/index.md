# 前端安全综述

前端安全是Web应用开发中至关重要的一环，涉及到保护用户数据、防止恶意攻击、确保应用正常运行等多个方面。

## 安全文档导航

- [Web前端安全指南](./web-frontend-security-guide.md)：全面介绍前端安全的基础概念、常见攻击类型和防御措施
- [JWT和OAuth2认证](./jwt-and-oauth2-authentication.md)：详细讲解JWT和OAuth2两种常用的身份认证机制的原理、实现和最佳实践

## 核心安全领域

1. **输入验证**：防止XSS、SQL注入等注入类攻击
2. **身份认证**：确保用户身份的真实性和合法性
3. **授权管理**：控制用户对资源的访问权限
4. **数据保护**：加密敏感数据，防止数据泄露
5. **通信安全**：使用HTTPS等安全协议保障数据传输安全
